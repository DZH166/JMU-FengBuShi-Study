# JMU-FengBuShi-Study

分布式系统交互学习手册。依据课程八章 PPT，按照问题与前置依赖重新组织为 32 个课时。

## 使用

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:4173`。ES Modules 与课程 JSON 通过 HTTP 加载，请使用服务器访问。

网站是纯静态文件，`dist/` 可部署到普通静态托管服务。路由使用 URL hash，直接打开课时链接无需服务端重写。

## 学习体验

- 八章课程地图与前置关系，32 个问题驱动课时。
- 完整机制讲解、具体过程、设计取舍、常见混淆与边界。
- RPC 重试、取模/一致性哈希、异步复制、多数派、2PC、MapReduce 六个离线实验。
- 可选理解题、错题解析、概念翻转卡与课时收藏。
- 沉浸阅读、字号调节、深色模式、手机适配与打印样式。
- 课时笔记自动保存，学习记录导出与合并导入。

学习数据只保存在当前浏览器的 localStorage。清理浏览数据、换设备或更换网站域名后不会自动迁移，请用「我的笔记」页面导出备份。已读与答题记录只描述相应操作，不代表长期掌握。

## 结构

```text
dist/
  index.html, app.js, style.css  页面与交互
  models.js                    可测试的教学模型
  content/ch01.json … ch08.json 课程正文与理解题
  content/method.json          学习方法
scripts/
  serve.mjs                    本地静态服务器
  check.mjs                    内容完整性与引用检查
tests/
  models.test.mjs              教学模型的边界与性质测试
evidence/
  chapters-*.md                内部来源映射和内容更正
  review-*.md                  独立复审记录
```

原始课件、全文转写、渲染页与联系图不提交到仓库。来源审查记录用于维护内容，未作为正文导航的一部分。

## 验证

```sh
npm run check
npm test
```

实验省略了真实网络、集群存储与生产环境的性能细节；各实验内注明具体假设。正文对原课件中的部分简化表述做了准确限定。一手资料核验与来源覆盖记录见 `evidence/`。

课程讲解和前端后续均可直接编辑。课时内容采用结构化 JSON，新增小节不需要修改页面代码。
